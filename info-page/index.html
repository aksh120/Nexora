Two-Tier Process Model

Nexora eliminates the multi-hundred-megabyte footprint of standard browsers by strictly separating desktop application management from web content rendering.

Nexora.exe (Native Host)
  • • Win32 Message Loop: Frameless DWM window geometry, native aero snap, and double-buffered GDI toolbar.
  • • Tab Manager: Persistent resident controller pool, drag-and-drop tab reordering, and hover preview cards.
  • • Audio Controller Sync: Per-tab volume state tracking and muting via COM IsMuted API.
  • • Suspension Engine: Inactive tabs unmapped from RAM (~1.5 KB kept in Rust); automated working set trimming.
  • • Embedded SQLite (WAL Mode): Atomic storage for bookmarks, history, and per-site zoom factors.
  • • In-Memory Bloom AdBlock: Pre-dispatch network filter permanently blocking trackers and telemetry.

msedgewebview2.exe (Render Runtime)
  • • W3C Web Standards Execution: HTML5 layout, CSS Flexbox/Grid, V8 JavaScript, WebAssembly, and WebAudio.
  • • Certified Widevine CDM: Hardware decryption for Netflix, Spotify, Disney+, and YouTube Premium.
  • • Direct3D 11 & NVDEC Offload: Zero-copy texture sharing directly between GPU decoder and compositor.
  • • Automated CVE Patching: Bi-weekly zero-day security updates delivered directly by Windows OS component.
  • • Child Process Sandboxing: Renderer memory scales dynamically with webpage content and video buffers.

Why WebView2?

Building a web engine from scratch cannot satisfy modern web specifications (>35M lines of code) or commercial Widevine DRM. Bundling Chromium requires 200 MB disk space and frequent manual updates. Nexora's hybrid model leverages the Windows Evergreen runtime, delivering full web compatibility, DRM compliance, and Direct3D 11 acceleration in a 1.46 MB binary.

YouTube Memory Reality

Modern YouTube is a heavy single-page application. Its Polymer component tree, comments, and recommendations require 90–130 MB of V8 heap memory. Maintaining smooth 60 FPS playback requires 80–150 MB of uncompressed decoded frame buffers. Nexora maintains video playback at 263 MB total memory—a 37% reduction compared to Chrome.

Multi-Controller Isolation

Nexora maintains resident ICoreWebView2Controller handles for background tabs. Tab switching executes native Win32 SetIsVisible(false) and SetIsVisible(true) calls in 14 ms without page reloads, preserving video playback timestamps, audio continuity, and form inputs.

Benchmark Methodology & Test Environment Specifications

Test Rig: Intel Core i7-3770 CPU @ 3.40 GHz (4 cores / 8 threads), 16.0 GB DDR3 @ 1600 MHz, NVIDIA GeForce GT 730 (Driver 474.11), Windows 11 Pro 64-bit (Build 22631).
Measurement Method: Captured via Windows Performance Counters and PowerShell management APIs (Get-Process -IncludeUserName | Measure-Object -Property WorkingSet64 -Sum). All background browser processes (browser coordinator, GPU process, network utility, and renderer workers) are summed for Chrome, Edge, and Nexora.
Run Count: Each scenario is executed 5 times; reported values reflect median measurements taken 30 seconds after navigation stabilization.

Engineered Capabilities

Features implemented natively in Rust and Win32, organized into four primary functional domains.

Browser Fundamentals

Find in Page Ctrl + F

Floating search toolbar positioned at the upper right. Features non-destructive DOM matching, live match counter (current / total), Enter/Shift+Enter navigation, and Escape dismissal.

Tab Audio Controls Per-Tab Muting

Visual audio state indicators on every tab. Clicking the audio glyph toggles mute immediately without switching active tab focus. Context menu provides "Mute other tabs" and "Unmute all tabs".

Drag-and-Drop Tab Rearrangement Mouse Drag

Reorder tabs smoothly with mouse drag. A 5-pixel drag threshold prevents accidental activation, and a vertical insertion indicator shows the drop target without reloading controllers.

Pinned Tabs Strip Context Menu

Compact 36px favicon-only tab pins locked to the left. Pinned tabs are protected from automated memory suspension and persist across browser restarts in SQLite.

Per-Site Persistent Zoom Ctrl + / - / 0

Independent zoom scaling from 50% to 200% keyed to website origins. Zoom levels are saved in local SQLite storage and automatically reapplied on return visits.

Tab Hover Previews 450 ms Hover

Non-blocking 450 ms hover preview card showing website favicon, page title, URL, rendered thumbnail, and audio/pin/suspension state badges without activating background tabs.

Media Experience

Advanced Picture-in-Picture Ctrl + Shift + P

Floating always-on-top video window with hover media controls, volume mute, and return-to-tab navigation. Playback continues uninterrupted when switching tabs or minimizing the browser.

Direct3D 11 & NVDEC Acceleration GPU Decode

Hardware-accelerated video decoding for H.264, VP9, and AV1 video streams via native GPU bitstream pipelines, reducing host CPU usage to under 3.5% during 1080p60 playback.

Certified Widevine CDM Pipeline Commercial DRM

Hardware-backed decryption pipeline supporting Netflix, Spotify, YouTube Premium, Disney+, and Amazon Prime Video without HDCP renegotiation errors.

Borderless Fullscreen F11

True full-display presentation that expands across the entire monitor canvas without title bar or taskbar intrusion.

Privacy & Security

Website Permissions Panel Omnibox Shield

Shield icon dropdown in the address bar displaying active permissions (Camera, Microphone, Geolocation, Notifications, Autoplay) with instant toggles saved per-origin in SQLite.

Bloom Filter AdBlock In-Memory

Outgoing network requests are intercepted before dispatch against an in-memory Bloom filter. Tracker pixels, cryptominers, and advertising domains are blocked without browser extensions.

Zero Telemetry Firewall Blocked

All Microsoft, Google, and third-party analytical, diagnostic, and reporting telemetry endpoints are permanently blocked at the request interceptor level.

Local SQLite (WAL Mode) Embedded DB

All user bookmarks, history, and permission entries are stored in an embedded SQLite database using Write-Ahead Logging for high-concurrency atomic transactions.

Performance & Persistence

Smart Tab Suspension Automated

Background tabs inactive past the configured timeout (default: 10 minutes) automatically release their WebView2 controllers, reducing memory consumption by up to 75%.

Working Set Memory Trimming Win32 API

Periodic system memory pressure evaluations invoke Win32 working set trims, returning unused physical memory to the operating system immediately.

Crash Recovery Checkpointing Atomic State

Session state is serialized atomically to disk upon navigation events, offering instant tab and scroll position recovery after abnormal shutdowns.

Native Setup Installer Win32 Binary

Standalone native installer (Nexora-Setup-v0.1.0.exe) with dark GDI GUI, silent installation mode (/S), COM shell links, and clean uninstaller.

Installation & Build Options

Choose between an automated Windows installer, a zero-install portable zip archive, or building from source with the standard Rust toolchain.

Windows Installer (.exe)

Installs Nexora into %LOCALAPPDATA%\Programs\Nexora, creates Desktop and Start Menu shortcuts, and registers a clean uninstaller in Windows Settings.

# Run silent installation without wizard: Nexora-Setup-v0.1.0.exe /S
Download Setup (.exe)
Portable Archive (.zip)

Standalone 1.32 MB zip archive. Extract to any directory or USB stick and run Nexora.exe. Requires no administrator permissions or registry modification.

# Extract and execute immediately: Expand-Archive Nexora-portable.zip -DestinationPath .\Nexora .\Nexora\Nexora.exe
Download Portable (.zip)
Building from Source

Prerequisites: Windows 10/11 x64, Rust toolchain (1.80+), and WebView2 Evergreen runtime. Build with Cargo:

git clone https://github.com/Nexora/Nexora.git cd Nexora cargo build --release cargo test
